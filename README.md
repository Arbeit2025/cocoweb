# cocoweb — Cocoa Mascot（Web試作）

**Live Demo:** https://cocoweb.onrender.com/

画面の下を歩く、Web版デスクトップマスコットの試作です。
PCのブラウザでもスマホのブラウザでも動きます。

## できること（試作版）

- 画面下を左右に散歩する（端で向きを変える、ときどき立ち止まる）
- キャラクターは元イラストに合わせた全身イラスト（`cocoa.png`、背景透過）。歩行時は全身の上下ゆれ＋左右の揺れで表現（旧SVG版にあった瞬き・足の個別アニメーションは画像版ではなし）
- タップ／クリックで吹き出しセリフ（ココアボタンの24種と共通、連続重複なし）＋小さくジャンプ
- ドラッグで好きな場所へ移動（離すと地面に戻る）
- 「散歩を止める／はじめる」「おすわり」ボタン
- 起動時に時間帯で挨拶が変わる（朝／昼／夕方／夜）
- 呼ばれた回数を累計／今日で表示（SQLite、ココアボタンと同じ方式）

## ローカル起動

```bash
pip install -r requirements.txt
python app.py
```

Flaskの開発サーバーは `flask --app app run` でも起動できます。

## 構成

- `app.py`：単一ファイル（Flask＋SQLite、`render_template_string`）
- `cocoa.png`：キャラクター全身イラスト（背景透過、`/cocoa.png` で配信）
- `tests/test_app.py`：表示・セリフ・カウント・画像配信・healthzのテスト
